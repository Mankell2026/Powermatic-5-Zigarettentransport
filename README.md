# Powermatic-5-Zigarettentransport
Kleines Projekt mit dem ESP32 und ANNEX RDS BASIC

--------------------------------------------------
Die Powermatic 5 Zigarettenstopfmaschine der ersten Generation hat Probleme, die fertigen Zigaretten auszustoßen.
Hier ein kleines Gerätchen, daß O H N E  Eingriff in die Elektronik der PM5 betrieben wird.
Ein kleiner ESP32 Mini D1, ein Mikromotor mit Getriebe und ein Mikroswitch reichen dazu aus.
Das ganze wird richtig positioniert an der PM 5 mit Klebestripes angebracht und mit einem kleinen USB AKKU betrieben.
Das Gerät ist über die integrierte Weboberfläche justierbar und einstellbar.
Der Mikroswitch fragt die Position des PM5- Hülsenhalters ab und steuert einstellbar den Mikromotor, der über eine Nocke den Transport der fertigen Zigarette
gewährleistet.
Kaufteile: ESP 32 Mini D1 ( WEMOS), Mikroswitch, Mikromotor. LED's, Widerstände 220 Ohm, Transistor, 2 Schrauben mit Muttern.
Das Gehäuse stammt komplett aus dem 3D Drucker
Coding: ANNEX RDS BASIC FW: 1.4...
